* cdb_patch_minimal.txt - LICENSED MODE (stock, EA-App-activated fifa.exe)
* ===========================================================================
* This build ships NO fifa.exe and NO awc.dll. The machine runs its OWN,
* genuinely EA-App-activated FIFA 12: PACE + the real 71055.dlf licence decrypt
* the .text and satisfy the DRM. NOTHING in this script touches the licence or
* PACE's decryption.
*
* What this script DOES is the private-server NETWORK layer + FUT enablement -
* exactly the functional patches that used to be BAKED into the cracked exe.
* On a stock exe they cannot be baked (the .text is PACE-ciphertext on disk),
* so they are re-applied at RUNTIME, after PACE has decrypted the code in
* memory. This is the same class of change as any community-server client
* patch (point the game at our server, accept our cert); it is NOT a DRM
* bypass - the game is licensed.
*
* THE ONE NEW MECHANISM vs the baked build: a HARDWARE execute breakpoint at
* the original entry point. fifa.exe is PACE-packed; its .text is ciphertext
* until PACE unpacks it and jumps to the OEP at 0x00b8df79. A software (int3)
* breakpoint there would be written into a ciphertext page and either be
* overwritten when PACE decrypts it, or trip PACE's tamper check. A HARDWARE
* breakpoint lives in the CPU debug registers, touches no memory, and fires the
* instant execution reaches the (now-decrypted) OEP. Everything that patches
* fifa.exe therefore happens AT that breakpoint, not before.
*
* ADDRESSES ARE ABSOLUTE VAs (ImageBase 0x400000, no ASLR) and are keyed to the
* game VERSION. This build targets the same version the patches were derived
* from; a different EA-App build would need them re-derived.
* ===========================================================================

.symopt+0x100
.sympath .
!sym quiet
.printf "--- FUT12 LICENSED MODE: runtime network+FUT patches on the stock exe ---\n"
.printf "--- symbols: local only, no unqualified loads, no symbol server ---\n"

* ---------------------------------------------------------------------------
* An access violation anywhere gets a full dump + stack, then continues. This
* is the primary diagnostic if the first launch does not reach FUT: the log
* names where and the dump carries the thread stacks. /o + relative path so it
* lands beside the game on any install (cdb runs -WorkingDirectory $GAME).
sxe -c ".echo ===AV_BEGIN===; r; u @eip L3; kv 30; .echo ---RAWSTACK---; dps @esp L40; .dump /o /mFhut fut12_crash.dmp; .echo ===AV_END===; gN" av

* ---------------------------------------------------------------------------
* Break at the OEP once PACE has decrypted .text. Hardware exec bp - survives
* the unpack, leaves no int3 in a packed page.
ba e1 b8df79
.printf "--- hardware bp armed at OEP 0x00b8df79; running until PACE unpacks ---\n"
g

* === STOPPED AT OEP: fifa.exe .text is now decrypted in memory =============
.printf "=== OEP reached: .text unpacked, applying network + FUT patches ===\n"

* --- cert path: make the client accept our self-signed Blaze cert -----------
* Without these the SSLv3 handshake to gosredirector aborts in ~15 ms and FUT
* shows "EA servers are not available". These make the post-parse trust checks
* pass; the public key is still extracted (needed for Client Key Exchange).
eb c995ea 90 90 90 90
eb c99639 90 90 90 90
eb c912f6 90 90
eb c9129c eb
eb c912c5 eb

* --- online-available flag: the string FUT selects is driven off this --------
eb be02eb 00
eb be04dd 00
eb bc69bf 00
eb be03f6 90 90 90 90 90

* --- DLC: load our real CardsDLLzf.dll (the one that talks to our server) ----
eb 4080bd 90 90 90 90 90 90
eb 40744d 90 90 90 90 90 90
eb 4040a1 eb

* --- FUT menu enablement + entitlement (EA's entitlement servers are dead) ---
eb 106da83 90 90
eb 121f595 33 c0 90
eb 12504f0 b0 01 c3

* --- stability: NULL AptString -> empty string (not an AV); larger EASTL pool
eb 4483cc eb 1c
eb 18b4312 39 39

* --- runtime hooks (software bps, valid now the .text is decrypted) ----------
* FUT availability gate - without this UT says the servers are unavailable
bp f728c0 "eb @ecx+0x13c 0; eb @ecx+0x14d 1; eb @ecx+0x14e 0; eb @ecx+0x14f 0; eb @ecx+0x150 0; ed @ecx+0x11c 1; ed @ecx+0x140 1; g"
* QoS values sent to Blaze: DBPS, NAT_TYPE_OPEN, UBPS
bp c61611 "ed poi(esp) 0x186a0; g"
bp c61638 "ed poi(esp) 0; g"
bp c61659 "ed poi(esp) 0x186a0; g"
* entitlement object populate (quantity=1, data-valid=1)
bp 125052b "ed poi(ebp-4)+0x164 1; eb poi(ebp-4)+0x1a0 1; g"
.printf "=== fifa.exe patches applied; arming awc handling ===\n"

* ---------------------------------------------------------------------------
* awc.dll loads AFTER the OEP (it is pulled in by the game's own code, not a
* static import). It is NOT PACE-packed, so its addresses are stable. Wait for
* it, then: init the one BSS global whose initializer never runs on a
* standalone launch, and suppress the origin:// EA-App relaunch (focus-steal).
* Neither is a DRM change - both just let fifa.exe run standalone cleanly.
sxe ld:awc
g
sxd ld
ed 4007ffc0 40062a88
eb 4001a5d1 e9 c8 03 00 00 90
bu awc+0x15ed2 "r eax=1; g"
.printf "--- awc mapped and patched; running the game ---\n"

g
